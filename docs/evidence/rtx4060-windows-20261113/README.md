# RTX 4060 Windows experiment — 2026-11-13

Windows 11, RTX 4060 Laptop GPU 8 GiB (SM89), driver 616.56, CUDA Toolkit 13.4.92 and MSVC 19.51, Release build. Tests on the measured build: CTest 5/5 and Compute Sanitizer 13.4 memcheck/racecheck for both GPU programs, four clean summaries. The negative control was run separately, not in that same check. All claims apply only to tested inputs.

- [`matrix-summary.csv`](matrix-summary.csv): 64 shapes × 2 sequential runs, Batch 1/2/4/8, Group 16/32/64/128, (N,K) = (65,129), (256,256), (1024,1024), (2048,4096). Each invocation checked CPU/GPU numerical agreement. Summary Direct, Grouped and two-pass measurements use different sample windows: do not interpret their ratios as paired statistical estimates. The two-pass path includes GPU weight dequantization and FP16 activation conversion before FP32 cuBLAS SGEMM. It is an unfused project reference, not an optimized industrial W4A16 baseline.
- [`target-tune-samples.csv`](target-tune-samples.csv) and [`target-choice-samples.csv`](target-choice-samples.csv): 20 independent runs of N1024/K256/B1/G64, each containing nine internal autotuner samples and nine subsequent Direct/Paired holdout samples. [`target-tuner-analysis.csv`](target-tuner-analysis.csv) records the per-run decisions and later holdout comparisons. The internal 10/50 warmup/repeat counts differ from the holdout 20/100; host submission gaps can affect CUDA Event measurements.
- [`accuracy.csv`](accuracy.csv): a later clean CUDA build of the same GPU operator source, 64 shapes × Direct, Grouped Paired, Grouped Scalar and two-pass cuBLAS. Each path compares 203,580 FP32 outputs against the same CPU reference; all mismatches are zero for `abs(error) <= 0.006 + 0.003*abs(reference)`. Across shapes, maximum absolute errors are Direct 1.52588e-5, Paired 1.14441e-5, Scalar 1.52588e-5 and two-pass 2.67029e-5. Maximum relative error divides by `max(1e-6, abs(reference))` and can be large near zero; it is not the acceptance criterion or a model-level accuracy claim. The seed is recorded per row. Run `scripts/accuracy_windows.ps1` with the new build and CUDA toolkit paths to reproduce.

The target tuner selection agreed with its own internal median in 20/20 runs and with the later holdout in 18/20; maximum observed holdout loss was 19.33%, not a bound on future loss. Clocks were not locked, GPU/CPU activity was not continuously monitored, and two rounds per matrix shape cannot establish stable performance. Host-synchronized Graph and device Event times have different scopes; no model-level throughput or industry comparison is implied.

Original local experiment directories, full logs and Compute Sanitizer files are under the ignored `validation/` workspace; they are not included in the public-ready source by default. `docs/OPTIMIZATION_20261112.md` and `docs/FINAL_EXPERIMENTS_20261113.md` explain A/A, AB/BA, observed regressions and scope. This directory contains a portable subset; reproduce new results with the project scripts and retain raw outputs.
